Sección C++ / Arduino

Práctica con Sensor de Humedad de Suelo

Código documentado para medir el nivel de humedad y mostrarlo mediante una barra de LEDs conectada en los pines 8 al 12:

int moisture = 0;

void setup() {
  pinMode(A0, OUTPUT); // Alimentación del sensor
  pinMode(A1, INPUT);  // Lectura del sensor
  Serial.begin(9600);

  // Configuración de la barra de LEDs
  pinMode(8, OUTPUT);
  pinMode(9, OUTPUT);
  pinMode(10, OUTPUT);
  pinMode(11, OUTPUT);
  pinMode(12, OUTPUT);
}

void loop() {
  // Encender el sensor solo para tomar la lectura (evita corrosión)
  digitalWrite(A0, HIGH);
  delay(10);
  moisture = analogRead(A1);
  digitalWrite(A0, LOW);

  Serial.println(moisture);

  // Apagar todos los LEDs de la barra
  digitalWrite(8, LOW);
  digitalWrite(9, LOW);
  digitalWrite(10, LOW);
  digitalWrite(11, LOW);
  digitalWrite(12, LOW);

  // Encender LED según la escala de humedad
  if (moisture < 200) {
    digitalWrite(12, HIGH);
  } else if (moisture < 400) {
    digitalWrite(11, HIGH);
  } else if (moisture < 600) {
    digitalWrite(10, HIGH);
  } else if (moisture < 800) {
    digitalWrite(9, HIGH);
  } else {
    digitalWrite(8, HIGH);
  }

  delay(100);
}

Sección Memorias, Bajo Nivel y Conceptos

1. Debugging (Depuración)

Es el proceso de buscar, encontrar y solucionar errores ("bugs") en el código[cite: 1]. Sus pasos principales son: reproducir el error, localizar el fallo, analizar la causa, corregir el código y probar la solución[cite: 1].

2. Lenguaje Ensamblador y Lenguaje Máquina

  • Ensamblador: Lenguaje de bajo nivel que sirve de puente directo entre el código fuente y las instrucciones de máquina de la CPU[cite: 3].
  • Ejemplo AVR (Arduino Uno - ATmega328P): Control de atenuación (fade) con PWM en el pin 9 modificando directamente el registro OCR1A[cite: 2].
  • Traducción a Hexadecimal y Binario: 
    sbi 0x04, 1   -> Hex: 9A 21 -> Binario: 1001 1010 0010 0001
clr r16       -> Hex: 27 00 -> Binario: 0010 0111 0000 0000

3. Álgebra de Boole y George Boole

George Boole unió la lógica filosófica con las matemáticas, reduciendo las operaciones a valores binarios: 1 (Verdadero) y 0 (Falso)[cite: 11]. Este sistema es la base del procesamiento de información en microchips[cite: 11].

4. Conversión Binario a Decimal

Ejemplo documentado: El número binario 11110010 equivale al decimal 242[cite: 4]:

128 + 64 + 32 + 16 + 0 + 0 + 2 + 0 = 242[cite: 4]
